# Mister-Wolfgang HA Addons

## 2way Audio Arenti

Bidirectional audio for Arenti/Meari cameras in Home Assistant.

- Send TTS / MP3 to camera speaker
- Use camera microphone as voice satellite (Whisper → LLM → TTS)
